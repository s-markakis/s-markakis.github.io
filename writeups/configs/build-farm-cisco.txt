! ===== LoRa GW — wAP LR8 · packet-forwarder to The Things Stack =====
! No Cisco box is a drop-in for a MikroTik wAP LR8. Cisco's LoRaWAN story is the
! IXM gateway + IoT Field Network Director, aimed at utilities and smart cities —
! heavy and licensed for a six-greenhouse farm. In practice you run ANY vendor's
! LoRaWAN gateway (RAK, Kerlink, a wAP LR8) pointed at The Things Stack; the router
! just carries its UDP 1700 packet-forwarder traffic on VLAN 35, exactly as here.
! The sensors are RF either way and never touch the IP network.
! ===== SXT pair — 5 GHz nv2 bridge carrying the control VLAN =====
! There is no nv2 on Cisco. For a 600 m point-to-point link Cisco's answer is the
! Catalyst IW (Industrial Wireless) or Ultra-Reliable Wireless Backhaul line — they
! do PtP well but cost far more than a pair of SXTs. What you give up dropping to
! plain 802.11 is nv2's TDMA scheduling: the trick that keeps a long, one-to-one
! link stable without CSMA back-off waiting for a faint, distant station. The VLAN
! trunk it carries (control VLAN 30 + mgmt) is identical whatever bridges the gap.

! ===== R1 — Starlink in bypass, recursive route kept by the DHCP client =====
! R1 — Starlink in bypass: the WAN takes the carrier-NAT address; IP SLA tracks it
interface GigabitEthernet0/0/0
 description Starlink (bypass)
 ip address dhcp
 ip nat outside
interface Cellular0/1/0
 description 4G backup
 ip nat outside
ip sla 1
 icmp-echo 1.1.1.1
 frequency 5
ip sla schedule 1 life forever start-time now
track 1 ip sla 1 reachability
ip route 0.0.0.0 0.0.0.0 dhcp 1 track 1
ip route 0.0.0.0 0.0.0.0 Cellular0/1/0 2
ip access-list standard NAT-ALL
 permit 10.60.0.0 0.0.255.255
ip nat inside source list NAT-ALL interface GigabitEthernet0/0/0 overload
! ===== Solar node — LtAP LR8 LTE · camera + LoRa repeater =====
! No single Cisco box is a solar-powered LoRa repeater + LTE camera node. The
! closest is an IR1101 industrial router: DIN-rail, wide-temperature, built-in LTE,
! low draw — but it has no LoRa concentrator, so a third-party gateway still rides
! alongside it. The hard part isn't the vendor anyway: the power budget (load x dark
! hours x a cloud margin -> battery, then panel) is identical whichever box it is.
! Over the LTE it dials the same FlexVPN tunnel home as R1.
! ===== R1 — WireGuard to the operator hub, alerts, remote logs =====
! R1 — FlexVPN client: dials out to the operator's hub through CGNAT
crypto ikev2 profile TO-HUB
 match identity remote fqdn hub.example.net
 identity local fqdn farm-r1.example.net
 authentication local rsa-sig
 authentication remote rsa-sig
 pki trustpoint OP-CA
 dpd 10 3 periodic
crypto ipsec profile TO-HUB
 set ikev2-profile TO-HUB
interface Tunnel1
 ip address 10.250.0.31 255.255.255.0
 tunnel source GigabitEthernet0/0/0
 tunnel destination dynamic
 tunnel protection ipsec profile TO-HUB
crypto ikev2 client flexvpn HUB
 peer 1 fqdn hub.example.net dynamic
 client connect Tunnel1
