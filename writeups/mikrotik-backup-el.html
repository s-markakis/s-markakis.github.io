MikroTik Backup
και Ανακτηση

Export εναντίον binary backup — για τι χρησιμεύει το καθένα, πότε να χρησιμοποιήσεις ποιο, και πώς να αυτοματοποιήσεις και τα δύο. Συν την πλήρη διαδικασία ανάκτησης με Netinstall για όταν ένας router δεν κάνει boot.

RouterOS Backup Export Recovery Netinstall Automation MTCNA+

Οι περισσότεροι operators MikroTik έχουν κάνει backup ακριβώς μία φορά — αμέσως μετά το setup — και δεν το ξανάγγιξαν. Μετά μια μέρα η flash storage χαλάει, ένα firmware update πάει στραβά, ή κάποιος διαγράφει κατά λάθος όλους τους κανόνες του firewall, και αυτό το backup από πριν 18 μήνες είναι το μόνο που υπάρχει. Αυτός ο οδηγός χτίζει μια πειθαρχία backup: τι κάνει κάθε format, πότε να χρησιμοποιήσεις ποιο, πώς να αυτοματοποιήσεις και τα δύο εκτός site, και τι κάνεις όταν ένας router δεν κάνει καν boot.

Το κομμάτι Netinstall στο τέλος είναι αυτό που θα χαρείς που διάβασες πριν το χρειαστείς. Η ανάκτηση ενός εντελώς μη αποκρινόμενου MikroTik είναι διαδικασία 15 λεπτών αν ξέρεις τα βήματα. Είναι σπιράλ πανικού αν δεν ξέρεις.

Προαπαιτουμενα
  • RouterOS v7.x — το backup syntax είναι σταθερό σε όλο το v7
  • Για αυτοματοποιημένο email backup: ρυθμισμένο SMTP (δες το tutorial Scripting)
  • Για Netinstall: ένα Windows PC, ένα καλώδιο Ethernet, και το πακέτο RouterOS .npk για το board σου
  • Για FTP backup: έναν FTP server στο LAN σου (προαιρετικό)

01

Export εναντιον Binary — Ποτε ποιο

Δεν είναι εναλλακτικές — εξυπηρετούν διαφορετικούς σκοπούς και πρέπει να τρέχεις και τα δύο τακτικά.

Η σωστή στρατηγική backup είναι και τα δύο: ένα νυχτερινό export που στέλνεται με email εκτός site (αναγνώσιμο, φορητό, ελέγξιμο) και ένα εβδομαδιαίο binary backup αποθηκευμένο τοπικά ή σε FTP (πλήρης κατάσταση συμπεριλαμβανομένων των credentials).

02

Export — Αναγνωσιμο Config

Το export παράγει ένα αρχείο .rsc με εντολές CLI. Μπορείς να το διαβάσεις, να το κάνεις diff, να το κάνεις paste, και να κάνεις restore από αυτό σε οποιοδήποτε hardware MikroTik.

Βασικες Εντολες Export

RouterOS — εντολες export 
# Export ολόκληρου config σε ένα αρχείο στο flash του router
[admin@MikroTik] > /export file=Hotel-01-backup
# Δημιουργεί το Hotel-01-backup.rsc στο flash storage του router

# Export με passwords συμπεριλαμβανόμενα (για disaster recovery — αποθήκευσέ το με ασφάλεια)
[admin@MikroTik] > /export file=Hotel-01-full show-sensitive
# ΠΡΟΣΟΧΗ: αυτό περιλαμβάνει όλα τα passwords σε plain text.
# Μεταχειρίσου αυτό το αρχείο με την ίδια προσοχή όπως τον password manager σου.

# Export μόνο ενός συγκεκριμένου τμήματος
[admin@MikroTik] > /ip firewall filter export file=firewall-rules
[admin@MikroTik] > /interface bridge export file=bridge-config
# Τα partial exports είναι χρήσιμα για documentation ή για να μοιραστείς συγκεκριμένα configs.

# Δες το export στο terminal (χωρίς να το αποθηκεύσεις σε αρχείο)
[admin@MikroTik] > /export
# Τυπώνει ολόκληρο το config στο terminal. Pipe μέσω less:
# /export | /file print (δεν υποστηρίζεται — χρησιμοποίησε file= και δες μέσω Winbox Files)

# Λίστα αρχείων στο flash storage
[admin@MikroTik] > /file print
 # NAME                  TYPE  SIZE    DATE
 0 Hotel-01-backup.rsc   .rsc  48KiB   may/02 02:00:01
Files › download .rsc file
Panel Files στο Winbox 4.1. Επίλεξε το αρχείο .rsc ή .backup και κάνε κλικ στο Download για να το αποθηκεύσεις στο laptop σου. Μπορείς επίσης να κάνεις drag αρχεία απευθείας από αυτό το panel στην επιφάνεια εργασίας σου. Χρησιμοποίησε το Upload για να στείλεις πίσω ένα αρχείο restore στον router.

Restore απο Export

RouterOS — restore απο export .rsc 
# Μέθοδος Α: import μέσω CLI (μετά την upload του .rsc στο flash του router)
[admin@MikroTik] > /import file=Hotel-01-backup.rsc
Opening script file Hotel-01-backup.rsc
Script file loaded and executed successfully
# Το αρχείο .rsc εκτελείται σαν script — κάθε γραμμή είναι μια εντολή CLI.
# Κάθε εντολή που αποτυγχάνει (π.χ. duplicate entry) τυπώνει error αλλά
# συνεχίζει την εκτέλεση — δεν σταματά στην πρώτη αποτυχία.

# Μέθοδος Β: paste στο terminal (για μικρά configs ή μερικό restore)
# Άνοιξε το αρχείο .rsc σε text editor, αντέγραψε όλες τις γραμμές,
# και κάνε paste στο terminal του Winbox. Ίδιο αποτέλεσμα με το import.

# Μέθοδος Γ: καθαρό restore — πρώτα reset, μετά import
[admin@MikroTik] > /system reset-configuration \
    no-defaults=yes \
    run-after-reset=Hotel-01-backup.rsc
# Καθαρίζει ΟΛΟ το config, μετά τρέχει αμέσως το .rsc στο reboot.
# Χρησιμοποίησέ το για ένα φρέσκο ξεκίνημα από ένα γνωστό-καλό export.
# ΠΡΟΣΟΧΗ: ο router θα κάνει reboot και θα χάσεις το session SSH σου.

03

Binary Backup — Πληρης Κατασταση

Το binary backup συλλαμβάνει ό,τι χάνει το export: passwords χρηστών, πιστοποιητικά, κλειδιά SSH, και ρυθμίσεις συστήματος. Χρησιμοποίησέ το για disaster recovery στην ίδια συσκευή.

RouterOS — εντολες binary backup 
# Δημιουργία binary backup (χωρίς κρυπτογράφηση password)
[admin@MikroTik] > /system backup save name=Hotel-01
Saving system configuration
Configuration backup saved
# Δημιουργεί το Hotel-01.backup στο flash storage.
# Το μέγεθος αρχείου είναι μεγαλύτερο από το .rsc — περιλαμβάνει τα πάντα.

# Δημιουργία κρυπτογραφημένου binary backup (συνιστάται για αποθήκευση εκτός site)
[admin@MikroTik] > /system backup save \
    name=Hotel-01-secure \
    password=YourStrongBackupPassword
# Κρυπτογραφημένο με AES. Απαιτεί password για restore.
# Αποθήκευσε το password ξεχωριστά από το αρχείο backup.

# Restore απο binary backup
[admin@MikroTik] > /system backup load name=Hotel-01
Restore and reboot? [y/N]: y
# Ο router κάνει reboot και επαναφέρεται στην κατάσταση του backup.
# Όλες οι τρέχουσες αλλαγές config από τότε που έγινε το backup χάνονται.

# Ή σε Winbox 4.1:
System › Backup › Save / Restore
System › Backup. Το Save δημιουργεί ένα αρχείο .backup στο flash. Βάλε ένα password για κρυπτογραφημένα backups που αποθηκεύονται εκτός site. Το Restore φορτώνει το αρχείο και κάνει αμέσως reboot — ανέβασε το αρχείο μέσω panel Files πρώτα αν δεν είναι ήδη στον router.
⚠ Παγιδα — Το Binary Backup Ειναι Ευαισθητο σε Εκδοση

Ένα αρχείο .backup που δημιουργήθηκε σε RouterOS 7.10 μπορεί να μην κάνει restore καθαρά σε 7.15. Το MikroTik γενικά υποστηρίζει restore από πρόσφατες προηγούμενες εκδόσεις, αλλά όχι από σημαντικά παλιότερες, και όχι από εντελώς διαφορετική major έκδοση. Σημείωνε πάντα την έκδοση RouterOS στο όνομα του αρχείου backup: Hotel-01-v7.15.backup. Αν κάνεις restore σε νέα συσκευή μετά από αντικατάσταση hardware, χρησιμοποίησε αντ' αυτού το export .rsc — είναι ανεξάρτητο από έκδοση και δουλεύει σε διαφορετικά μοντέλα hardware.

04

Αυτοματο Backup σε FTP και USB

Τα τοπικά backups προστατεύουν από λάθη config. Τα backups εκτός site προστατεύουν από βλάβη hardware. Τρέξε και τα δύο σε προγραμματισμό.

Auto-Backup σε FTP

RouterOS — προγραμματισμενο backup σε FTP server 
# Όνομα script: ftp-backup
# Τρέχει κάθε βράδυ στις 03:00
:local hostname [/system identity get name]
:local date [/system clock get date]
:local filename ($hostname . "-" . $date)

# Δημιουργία και των δύο τύπων backup
/export file=$filename
/system backup save name=$filename

# Upload .rsc στον server FTP
:do {
    /tool fetch \
        address=192.168.20.100 \
        src-path=($filename . ".rsc") \
        dst-path=("/" . $hostname . "/" . $filename . ".rsc") \
        user=backupuser \
        password=ftppassword \
        upload=yes \
        mode=ftp
    :log info ("FTP backup uploaded: " . $filename)
} on-error={
    :log warning ("FTP backup FAILED: " . $filename)
}

# Καθάρισμα παλιών τοπικών αρχείων — κράτα τα τελευταία 7
:local rscFiles [/file find where name~($hostname) \
    and name~".rsc"]
:while ([:len $rscFiles] > 7) do={
    /file remove ($rscFiles->0)
    :set rscFiles [/file find where name~($hostname) \
        and name~".rsc"]
}

Auto-Backup σε USB Drive

RouterOS — backup σε USB (οταν το δισκος USB ειναι mounted) 
# Το USB εμφανίζεται ως disk στο /file — έλεγξε πρώτα ότι υπάρχει
:local usbDisk [/file find where type=disk]
:if ([:len $usbDisk] = 0) do={
    :log warning "USB disk not found — backup skipped"
    :error "no USB"
}

:local diskName [/file get ($usbDisk->0) name]
:local hostname [/system identity get name]
:local date [/system clock get date]
:local target ($diskName . "/" . $hostname . "-" . $date)

/export file=$target
/system backup save name=$target
:log info ("USB backup saved to " . $target)
# Τα αρχεία αποθηκεύονται απευθείας στο path του δίσκου USB.
# Χρήσιμο για routers σε απομακρυσμένα sites όπου email/FTP δεν είναι αξιόπιστα.

05

Netinstall — Ανακτηση ενος Bricked Router

Όταν το RouterOS δεν κάνει boot, το Netinstall επανεγκαθιστά το OS μέσω Ethernet από ένα Windows PC. Δεκαπέντε λεπτά από brick σε δουλεύοντα router.

Το Netinstall είναι ένα εργαλείο Windows που κάνει boot μια συσκευή MikroTik σε ειδική λειτουργία network bootstrap και γράφει μια φρέσκια εγκατάσταση RouterOS απευθείας στο flash της. Δουλεύει σε εντελώς μη αποκρινόμενους routers — χωρίς RouterOS να τρέχει, χωρίς πρόσβαση Winbox, χωρίς SSH. Όσο το hardware δεν είναι φυσικά κατεστραμμένο, το Netinstall μπορεί να το ανακτήσει.

Netinstall Βημα προς Βημα

1

Κατεβασε το Netinstall από το mikrotik.com/download — μόνο Windows. Κατέβασε επίσης το πακέτο RouterOS .npk για την αρχιτεκτονική του board σου (ARM, MIPSBE, x86, κλπ). Έλεγξε την αρχιτεκτονική του board σου με /system resource print πριν κάνει brick, ή ψάξ' το στο MikroTik wiki με το όνομα μοντέλου.

2

Ρύθμισε τον adapter Ethernet του PC σου σε static IP: 192.168.0.1 / 255.255.255.0, χωρίς gateway, χωρίς DNS. Σύνδεσε ένα απευθείας καλώδιο Ethernet από το PC σου στη θύρα ether1 του MikroTik (ή τη θύρα με ετικέτα "Boot" σε κάποια μοντέλα). Απενεργοποίησε το WiFi στο PC σου — το Netinstall πρέπει να χρησιμοποιεί μόνο τον ενσύρματο adapter.

3

Άνοιξε το Netinstall ως Administrator. Βάλε το "Net booting" IP σε 192.168.0.100 (αυτή είναι η IP που θα δώσει το Netinstall στον router κατά το flashing). Τσέκαρε το "Net boot" για να το ενεργοποιήσεις. Επίλεξε το αρχείο πακέτου .npk. Μην τσεκάρεις το "Keep old configuration" αν κάνεις καθαρή ανάκτηση.

4

Κάνε boot το MikroTik σε λειτουργία Netinstall. Κράτα πατημένο το κουμπί Reset ενώ συνδέεις το ρεύμα. Κράτα το πατημένο μέχρι το LED ACT/USR να αρχίσει να αναβοσβήνει γρήγορα (συνήθως 3–5 δευτερόλεπτα). Άφησέ το. Ο router είναι τώρα σε λειτουργία network boot του Netinstall. Η συσκευή θα πρέπει να εμφανιστεί στη λίστα συσκευών του Netinstall μέσα σε 10–15 δευτερόλεπτα.

5

Επίλεξε τη συσκευή στο Netinstall και κάνε κλικ στο Install. Το flashing παίρνει 1–3 λεπτά. Ο router κάνει reboot αυτόματα όταν τελειώσει. Μην αποσυνδέσεις το ρεύμα κατά τη διάρκεια αυτής της διαδικασίας.

6

Μετά το reboot, συνδέσου στον router στο 192.168.88.1 (default IP μετά από καθαρή εγκατάσταση). Username admin, χωρίς password. Ανέβασε αμέσως το πιο πρόσφατο export .rsc σου μέσω Winbox Files και τρέξε /import file=your-backup.rsc. Το πλήρες config σου επαναφέρεται.

RouterOS — restore config μετα το Netinstall 
# Μετά το Netinstall, ο router είναι στα factory defaults.
# Συνδέσου μέσω Winbox στο 192.168.88.1, admin / χωρίς password.
# Ανέβασε το αρχείο .rsc σου μέσω panel Files, μετά:
[admin@MikroTik] > /import file=Hotel-01-backup.rsc
Script file loaded and executed successfully
# Μετά βάλε το password του admin (δεν είναι στο export):
[admin@MikroTik] > /user set admin password=YourNewPassword
# Ο router είναι πίσω. Συνολικός χρόνος ανάκτησης από brick: ~15 λεπτά.
⚠ Παγιδα — Το Netinstall Δεν Βλεπει τη Συσκευη;

Τρία πράγματα να ελέγξεις: πρώτον, ο adapter Ethernet του PC σου πρέπει να είναι σε static IP 192.168.0.1 — το DHCP δεν θα δουλέψει. Δεύτερον, απενεργοποίησε προσωρινά το Windows Firewall — μπορεί να μπλοκάρει την κίνηση TFTP του Netinstall. Τρίτον, βεβαιώσου ότι κρατάς το Reset πριν συνδέσεις το ρεύμα, όχι μετά. Σε κάποια μοντέλα η ακολουθία boot είναι πολύ γρήγορη — έχεις λιγότερο από 1 δευτερόλεπτο μετά το power-on για να πυροδοτήσεις τη λειτουργία network boot. Αν ακόμα δεν δουλεύει, δοκίμασε διαφορετικό καλώδιο Ethernet και επιβεβαίωσε ότι είσαι συγκεκριμένα στο ether1.

✕ Τι Δεν Δουλεψε — Restore ενος Αρχειου .backup Μετα το Netinstall

Αφού το Netinstall εγκαταστήσει ένα φρέσκο RouterOS 7.15, η προσπάθεια restore ενός αρχείου .backup από RouterOS 7.10 συχνά καταλήγει σε μερικό restore ή boot loop. Το format binary backup είναι ευαίσθητο σε έκδοση. Η σωστή προσέγγιση: μετά το Netinstall, κάνε restore από το export .rsc (που είναι ανεξάρτητο από έκδοση), μετά επαναρύθμισε χειροκίνητα τυχόν passwords και πιστοποιητικά. Ακριβώς γι' αυτό χρειάζεσαι και τους δύο τύπους backup — το .rsc είναι το δίχτυ ασφαλείας σου όταν το binary backup δεν μπορεί να χρησιμοποιηθεί.

🛡 Ματια Operator — Στρατηγικη Backup για Production

Ο κανόνας 3-2-1 για configs router. Τρία αντίγραφα: ο live router, ένα τοπικό backup στο NAS ή τον FTP server σου, και ένα εκτός site (email ή cloud). Δύο formats: export .rsc και binary .backup. Μία τοποθεσία εκτός site. Αν έχεις μόνο τοπικό backup και το δωμάτιο του router πλημμυρίσει ή καεί, δεν έχεις τίποτα. Το email είναι ο απλούστερος τρόπος εκτός site — ένα νυχτερινό .rsc στα εισερχόμενά σου σημαίνει ότι μπορείς να κάνεις restore από οπουδήποτε με μόνο ένα laptop.

Κάνε versioning το export σε git. Επειδή το .rsc είναι plain text, είναι τέλειο για git. Το git diff ανάμεσα σε δύο exports σου δείχνει ακριβώς τι άλλαξε ανάμεσα σε Δευτέρα και Παρασκευή — ποιοι κανόνες firewall προστέθηκαν, ποιες IPs άλλαξαν, ποια VLANs τροποποιήθηκαν. Για ένα ακίνητο που διαχειρίζονται πολλοί άνθρωποι, αυτό το audit trail είναι ανεκτίμητο. Ακόμα και ένα private GitHub repo με ένα νυχτερινό commit script είναι αρκετό.

Κράτα ένα USB stick Netinstall σε κάθε site. Ένα USB stick με το executable του Netinstall και το σωστό RouterOS .npk για το μοντέλο hardware κάθε site σημαίνει ότι οποιοδήποτε μέλος του προσωπικού μπορεί να το δώσει σε έναν τεχνικό και η ανάκτηση μπορεί να ξεκινήσει χωρίς να περιμένει downloads. Ετικέτα με το μοντέλο board και την τελευταία δοκιμασμένη έκδοση RouterOS.

Δοκίμασε τη διαδικασία restore σου πριν τη χρειαστείς. Μια φορά τον χρόνο, πάρε έναν εφεδρικό router (ή ένα CHR VM), κάνε ένα καθαρό Netinstall, κάνε restore από το τελευταίο backup σου, και επιβεβαίωσε ότι όλα δουλεύουν. Το backup που δεν έχει δοκιμαστεί ποτέ δεν είναι backup — είναι ελπίδα.

Βασικα Συμπερασματα

  1. Κράτα παντα και τα δύο formats. Export .rsc για φορητότητα, auditability, και restore μεταξύ εκδόσεων. Binary .backup για πλήρες disaster recovery στην ίδια συσκευή συμπεριλαμβανομένων passwords και πιστοποιητικών. Το ένα χωρίς το άλλο αφήνει κενά.
  2. Το export δεν περιλαμβάνει passwords. Μετά από restore από ένα .rsc, πρέπει να επαναφέρεις το password του admin και τυχόν credentials API χειροκίνητα. Καταγράψε τα ξεχωριστά από το αρχείο backup.
  3. Τα binary backups είναι ευαίσθητα σε έκδοση. Σημείωνε πάντα την έκδοση RouterOS στο όνομα του αρχείου backup. Αν το hardware σου αντικατασταθεί ή η έκδοση διαφέρει σημαντικά, χρησιμοποίησε το export .rsc για restore.
  4. Αυτοματοποίησε και τα δύο backups σε προγραμματισμό και στείλε τουλάχιστον ένα εκτός site. Ένα backup που υπάρχει μόνο στο flash του router χάνεται αν το flash χαλάσει — ακριβώς όταν το χρειάζεσαι περισσότερο. Το email είναι ο απλούστερος μηχανισμός εκτός site.
  5. Το Netinstall μπορεί να ανακτήσει οποιοδήποτε MikroTik που δεν είναι φυσικά κατεστραμμένο. Κράτα το Reset πριν το ρεύμα, σύνδεσε στο ether1, static IP 192.168.0.1 στο PC σου, απενεργοποίησε το WiFi. Όλη η διαδικασία παίρνει 15 λεπτά. Διάβασε τη διαδικασία πριν τη χρειαστείς, όχι κατά τη διάρκεια μιας διακοπής στις 02:00.
  6. Μετά το Netinstall, κάνε restore από .rsc όχι binary backup. Η φρέσκια έκδοση RouterOS μπορεί να διαφέρει από την έκδοση του backup. Το text export είναι πάντα ασφαλές να γίνει import ανεξάρτητα από έκδοση.
  7. Δοκίμασε τη διαδικασία restore σου κάθε χρόνο σε εφεδρική συσκευή ή CHR VM. Ένα backup που δεν έχει δοκιμαστεί ποτέ δεν είναι backup.

Τι γινεται οταν ο router σου απλα πεθαινει;

Κάθε ακίνητο που διαχειρίζομαι παίρνει την ίδια πειθαρχία backup: νυχτερινά config exports με email εκτός site, binary backups σε τοπικό NAS, και ένα recovery kit Netinstall που κάθεται στο ίδιο το site για τη μέρα που ένας router απλά πεθαίνει.
