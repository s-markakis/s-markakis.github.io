Τερματικο RouterOS
για Φοιτητες MTCNA

Ξέρεις τη θεωρία. Τώρα μάθε να την πληκτρολογείς. Το CLI του RouterOS είναι πιο γρήγορο, πιο ακριβές, και πιο scriptable από το Winbox — αυτό το tutorial σε κάνει άνετο σε αυτό από το μηδέν.

RouterOS CLI Terminal SSH Winbox Terminal MTCNA Beginner

Κάθε κλικ στο Winbox αντιστοιχεί σε μια εντολή CLI. Μόλις το ξέρεις αυτό, το terminal σταματά να είναι τρομακτικό και αρχίζει να είναι πιο γρήγορο. Μπορείς να ρυθμίσεις 20 κανόνες firewall στον χρόνο που παίρνει να κάνεις κλικ σε 3 στο Winbox. Μπορείς να κάνεις paste ένα script, να κάνεις grep output, και να κάνεις pipe αποτελέσματα — τίποτα από αυτά δεν υποστηρίζει το Winbox. Και στο πεδίο, όταν το Winbox δεν συνδέεται, το SSH πάντα θα συνδεθεί.

Αυτό το tutorial είναι φτιαγμένο για φοιτητές MTCNA που ήδη καταλαβαίνουν τι είναι μια διεύθυνση IP, ένα bridge, και ένα chain firewall — αλλά που απέφευγαν το μαύρο κουτί στο κάτω μέρος του Winbox. Ξεκινάμε με εντολές ανάγνωσης μηδενικού ρίσκου, χτίζουμε προς σίγουρες επεξεργασίες, και τελειώνουμε με τις συντομεύσεις πληκτρολογίου και τα patterns που κάνουν τους έμπειρους operators γρήγορους.

Προαπαιτουμενα
  • Έναν router MikroTik που τρέχει RouterOS v7.x (φυσικό ή CHR)
  • Πρόσβαση μέσω SSH ή του ενσωματωμένου terminal του Winbox 4.1 (κουμπί New Terminal)
  • Γνώση επιπέδου MTCNA — ξέρεις τι είναι bridges, IPs, και chains firewall
  • Δεν απαιτείται προηγούμενη εμπειρία CLI — αλλά ούτε φόβος ενός κενού prompt

01

Ανοιγοντας το Τερματικο

Δύο τρόποι να μπεις — SSH από το μηχάνημά σου, ή το ενσωματωμένο terminal στο Winbox 4.1. Και τα δύο σου δίνουν το ίδιο shell RouterOS.

Μεθοδος Α — Ενσωματωμενο Τερματικο Winbox 4.1

Το ευκολότερο σημείο εκκίνησης. Άνοιξε το Winbox 4.1, συνδέσου στον router σου, μετά κάνε κλικ στο New Terminal στο πάνω toolbar. Ένα panel terminal ανοίγει μέσα στο παράθυρο του Winbox. Είσαι ήδη συνδεδεμένος — δεν χρειάζεται setup SSH.

Tools › New Terminal
Winbox 4.1 → κάνε κλικ στο New Terminal στο πάνω toolbar. Το panel terminal ανοίγει στα δεξιά. Το logo του MikroTik εμφανίζεται, μετά το prompt. Είσαι μέσα.

Μεθοδος Β — SSH απο το Μηχανημα σου

Το SSH σου δίνει το ίδιο shell αλλά από οποιαδήποτε συσκευή στο δίκτυο — ή απομακρυσμένα μέσω Tailscale. Το RouterOS τρέχει έναν server SSH στη θύρα 22 by default.

Το laptop σου — συνδεσου μεσω SSH 
# Αντικατέστησε το 192.168.88.1 με τη διεύθυνση IP του router σου
user@laptop:~$ ssh admin@192.168.88.1
admin@192.168.88.1's password: 
# Πληκτρολόγησε το password σου — τίποτα δεν εμφανίζεται καθώς πληκτρολογείς, είναι φυσιολογικό.

  MMM      MMM       KKK                          TTTTTTTTTTT      KKK
  ...
  RouterOS 7.15 (c) 1999-2026
  Press F1 for help

[admin@MikroTik] >   ← τώρα είσαι μέσα στο shell του RouterOS
⚠ Παγιδα — Το SSH Δεν Συνδεεται;

Αν το SSH απορρίπτεται, έλεγξε δύο πράγματα. Πρώτο: /ip service print — το SSH (θύρα 22) δεν πρέπει να είναι απενεργοποιημένο. Δεύτερο: το input chain του firewall σου πρέπει να δέχεται TCP θύρα 22 από την source IP σου. Αν κλείδωσες το SSH σε ένα VLAN management (όπως συνιστάται στο tutorial Firewall), πρέπει να συνδεθείς από μια συσκευή σε εκείνο το VLAN. Αν έχεις κλειδωθεί εντελώς έξω, χρησιμοποίησε αντ' αυτού το terminal του Winbox — παρακάμπτει το firewall.

02

Ανατομια του Prompt

Το prompt σου λέει ακριβώς πού είσαι και ποιος είσαι. Διάβασέ το πριν πληκτρολογήσεις οτιδήποτε.

Το prompt του RouterOS έχει τρία μέρη:

RouterOS — ανατομια prompt 
[admin@MikroTik] >
 │      │          │
 │      │          └─ το > σημαίνει ότι είσαι στο root context
 │      └──────────── hostname αυτού του router
 └─────────────────── username με το οποίο έκανες login

[admin@MikroTik] /ip/firewall/filter>
 │                    │
 │                    └─ path τρέχοντος context — σαν φάκελος στον οποίο είσαι "μέσα"
 └──────────────────── username@hostname (εμφανίζεται πάντα)

Το context (το path μετά το hostname) είναι το ισοδύναμο του RouterOS ενός directory. Όταν κάνεις navigate μέσα σε ένα context, οι εντολές εφαρμόζονται σε εκείνο το τμήμα του router. Το /ip/firewall/filter> σημαίνει ότι κάθε εντολή που πληκτρολογείς δρα πάνω στους κανόνες filter του firewall. Γι' αυτό δεν χρειάζεται να πληκτρολογείς το πλήρες path κάθε φορά.

RouterOS — πλοηγηση σε contexts 
# Ξεκίνα στο root
[admin@MikroTik] > ip firewall filter
[admin@MikroTik] /ip/firewall/filter> ← τώρα μέσα στο context filter

# Ανέβα ένα επίπεδο με ".."
[admin@MikroTik] /ip/firewall/filter> ..
[admin@MikroTik] /ip/firewall>

# Γύρνα πίσω στο root με "/"
[admin@MikroTik] /ip/firewall> /
[admin@MikroTik] >

# Πήδα απευθείας σε οποιοδήποτε context από οπουδήποτε χρησιμοποιώντας πλήρες path
[admin@MikroTik] > /interface bridge
[admin@MikroTik] /interface/bridge>

03

Οι Καλυτεροι σου Φιλοι: Tab και ?

Δεν χρειάζεται να απομνημονεύεις εντολές. Το Tab τις συμπληρώνει. Το ? λιστάρει τι είναι διαθέσιμο. Αυτά τα δύο κουμπιά κάνουν το CLI πιο γρήγορο από το Winbox.

Tab — Autocomplete

Πάτα Tab αφού πληκτρολογήσεις τα πρώτα λίγα γράμματα οποιασδήποτε εντολής ή παραμέτρου. Το RouterOS τη συμπληρώνει. Αν υπάρχουν πολλαπλά matches, πάτα Tab ξανά για να κάνεις κύκλο ανάμεσά τους.

RouterOS — Tab autocomplete σε δραση 
[admin@MikroTik] > in[Tab]
interface             ← συμπληρώθηκε σε "interface"

[admin@MikroTik] > interface bri[Tab]
interface bridge      ← συμπληρώθηκε σε "bridge"

[admin@MikroTik] > ip fir[Tab] filt[Tab] pr[Tab]
ip firewall filter print   ← ολόκληρη εντολή χτισμένη με Tab

# Το Tab επίσης συμπληρώνει ονόματα και τιμές παραμέτρων:
[admin@MikroTik] /ip/firewall/filter> add chain=[Tab]
forward  input  output   ← δείχνει έγκυρες επιλογές για chain=

? — Βοηθεια Ευαισθητη στο Context

Πληκτρολόγησε ? σε οποιοδήποτε σημείο για να δεις ποιες εντολές ή παράμετροι είναι διαθέσιμες. Δουλεύει στο root, μέσα σε ένα context, στη μέση εντολής, ή μετά από ένα όνομα παραμέτρου.

RouterOS — βοηθεια ? σε διαφορετικα σημεια 
# ? στο root — λιστάρει όλα τα top-level μενού
[admin@MikroTik] > ?
  interface      -- Interface configuration
  ip             -- IP configuration
  bridge         -- Bridge configuration
  routing        -- Routing configuration
  system         -- System settings
  ...

# ? μετά από μια εντολή — λιστάρει παραμέτρους
[admin@MikroTik] /ip/firewall/filter> add ?
  action         -- Rule action (accept/drop/reject/log...)
  chain          -- Chain name (input/forward/output)
  comment        -- Short description
  connection-state -- established/new/related/invalid
  dst-address    -- Destination address
  ...

# ? στη μέση παραμέτρου — δείχνει έγκυρες τιμές
[admin@MikroTik] /ip/firewall/filter> add action=?
  accept  drop  reject  log  passthrough  tarpit  return

F1 — Πληρης Σελιδα Βοηθειας

Πάτα F1 σε οποιοδήποτε prompt για να δεις μια μορφοποιημένη σελίδα βοήθειας για το τρέχον context. Πιο λεπτομερής από το ?, λιγότερο φορτωμένη από το wiki.

↑ ↓ — Ιστορικο Εντολων

Πάτα ↑ για να κάνεις κύκλο μέσα από προηγούμενες πληκτρολογημένες εντολές. Εξοικονομεί τεράστιο χρόνο όταν επαναλαμβάνεις παρόμοιες εντολές με μικρές αλλαγές.

💡 Pro Tip — Χτισε Εντολες με Tab Πριν Πατησεις Enter

Το επαγγελματικό workflow: πληκτρολόγησε 2–3 χαρακτήρες, πάτα Tab, έλεγξε το autocomplete, συνέχισε. Μην πληκτρολογείς ποτέ μια πλήρη εντολή από μνήμης. Αυτό πιάνει typos πριν εκτελεστούν και σε βοηθά να ανακαλύψεις ονόματα παραμέτρων που δεν ήξερες ότι υπήρχαν. Αν δεν είσαι σίγουρος αν μια εντολή είναι ασφαλής να τρέξει, χρησιμοποίησε ? για να διαβάσεις τι κάνει πρώτα.

04

Ασφαλεις Εντολες Αναγνωσης Ασφαλες να Τρεξεις

Ξεκίνα εδώ. Αυτές οι εντολές διαβάζουν και εμφανίζουν πληροφορίες — δεν αλλάζουν τίποτα. Τρέξ' τες ελεύθερα σε οποιονδήποτε live router.

Κάθε τμήμα του RouterOS έχει μια εντολή print. Είναι πάντα ασφαλής. Σου δείχνει την τρέχουσα κατάσταση όποιου context βρίσκεσαι. Εδώ πρέπει να ξεκινούν όλα τα sessions CLI — κατάλαβε τι υπάρχει πριν αλλάξεις οτιδήποτε.

RouterOS — βασικες εντολες print (ολες μονο-αναγνωσης) 
# Σε ποιον είμαι συνδεδεμένος; Ποια έκδοση;
[admin@MikroTik] > /system identity print
  name: MikroTik

[admin@MikroTik] > /system resource print
  uptime: 14d 06:22:11
  version: 7.15 (stable)
  board-name: RB750Gr3
  cpu-load: 3 %
  free-memory: 89.6MiB

# Ποια interfaces υπάρχουν;
[admin@MikroTik] > /interface print
Flags: D - dynamic, X - disabled, R - running, S - slave
 #     NAME       TYPE    MTU    L2MTU  MAX-L2MTU
 0  R  ether1     ether   1500   1598   4074
 1  R  ether2     ether   1500   1598   4074
 2  R  wlan1      wlan    1500   1600   2290
 3  R  bridge1    bridge  1500

# Ποιες διευθύνσεις IP είναι ανατεθειμένες;
[admin@MikroTik] > /ip address print
 #   ADDRESS           NETWORK        INTERFACE
 0   192.168.88.1/24   192.168.88.0   bridge1
 1   192.168.10.1/24   192.168.10.0   vlan10

# Ποια routes υπάρχουν;
[admin@MikroTik] > /ip route print
 #    DST-ADDRESS   GATEWAY       DISTANCE
 0 A  0.0.0.0/0     192.168.1.1   1        ← default route (A = ενεργο)

# Ποιοι κανόνες firewall είναι ρυθμισμένοι;
[admin@MikroTik] > /ip firewall filter print
 0  chain=input  action=accept  connection-state=established,related
 1  chain=input  action=drop    connection-state=invalid
 2  chain=input  action=drop    (final drop-all)

# Ποια leases DHCP είναι ενεργά;
[admin@MikroTik] > /ip dhcp-server lease print
 #  ADDRESS          MAC-ADDRESS        HOST-NAME    STATUS
 0  192.168.10.100   AA:BB:CC:DD:EE:FF  staff-pc     bound

Φιλτραρισμα του Output του Print

Το print μπορεί να φιλτραριστεί με where για να στενέψει τα αποτελέσματα. Αυτό είναι ένα από τα πιο χρήσιμα patterns CLI — ισοδύναμο με αναζήτηση στο Winbox αλλά πιο γρήγορο.

RouterOS — φιλτραρισμενο print με where 
# Δείξε μόνο running interfaces
[admin@MikroTik] > /interface print where running=yes

# Δείξε μόνο ενεργά routes
[admin@MikroTik] > /ip route print where active=yes

# Δείξε κανόνες firewall που χρησιμοποιούν action=drop
[admin@MikroTik] > /ip firewall filter print where action=drop

# Βρες ένα lease DHCP κατά hostname (~ σημαίνει "περιέχει")
[admin@MikroTik] > /ip dhcp-server lease print where host-name~"camera"
 0  192.168.40.12   AA:BB:CC:11:22:33  camera-lobby  bound

# Δείξε μόνο το default route
[admin@MikroTik] > /ip route print where dst-address=0.0.0.0/0

print detail — Δες τα Παντα

Το κανονικό print δείχνει έναν πίνακα σύνοψης. Πρόσθεσε detail για να δεις κάθε παράμετρο κάθε καταχώρησης — χρήσιμο κατά το debugging ή όταν χρειάζεσαι ένα πεδίο που είναι κρυμμένο στην προβολή πίνακα.

RouterOS — print detail 
[admin@MikroTik] > /interface bridge print detail
 0  R  name="bridge1" mtu=1500 actual-mtu=1500 l2mtu=1596
        arp=enabled arp-timeout=auto mac-address=AA:BB:CC:DD:EE:FF
        protocol-mode=rstp fast-forward=yes
        vlan-filtering=yes frame-types=admit-all
# Κάθε πεδίο εμφανίζεται, συμπεριλαμβανομένων αυτών που δεν φαίνονται στο κανονικό print.

05

Κατανοηση της Δομης Εντολων

Κάθε εντολή RouterOS ακολουθεί το ίδιο pattern. Μάθε το pattern μία φορά και μπορείς να κατασκευάσεις οποιαδήποτε εντολή χωρίς να την απομνημονεύσεις.

Το path μπορεί να δοθεί inline (πριν το verb) ή μπορείς να κάνεις navigate μέσα στο context πρώτα. Και τα δύο είναι ισοδύναμα:

RouterOS — inline path εναντιον navigation context (ιδιο αποτελεσμα) 
# Style Α: πλήρες inline path (καλό για scripts και one-liners)
[admin@MikroTik] > /ip firewall filter print

# Style Β: κάνε navigate πρώτα, μετά εντολή (καλό για interactive sessions)
[admin@MikroTik] > /ip firewall filter
[admin@MikroTik] /ip/firewall/filter> print

# Και τα δύο παράγουν πανομοιότυπο output. Χρησιμοποίησε το Style Α σε scripts, το Style Β όταν
# κάνεις πολλαπλές αλλαγές στο ίδιο τμήμα interactively.

06

Κανοντας Αλλαγες Τροποποιει Config

Add, set, remove, enable, disable — τα πέντε verbs που αλλάζουν πράγματα. Πάντα print πρώτα, άλλαξε δεύτερο, επαλήθευσε τρίτο.

⚠ Χρησιμοποιησε Safe Mode Πριν Κανεις Αλλαγες

Πληκτρολόγησε /system safe-mode πριν κάνεις αλλαγές σε έναν live router. Το safe mode σου δίνει ένα αυτόματο παράθυρο rollback 9 λεπτών — αν κλειδωθείς έξω ή σπάσεις κάτι, ο router επαναφέρει αυτόματα όλες τις αλλαγές όταν λήξει το timer. Επιβεβαίωσε με Ctrl+X για να κρατήσεις τις αλλαγές, ή απλά αποσυνδέσου για να κάνεις rollback. Αυτό δεν είναι διαπραγματεύσιμο σε οποιονδήποτε router που έχει ενεργούς χρήστες.

RouterOS — add, set, remove, enable, disable 
# ── ADD: δημιούργησε μία νέα καταχώρηση ────────────────────────────────
[admin@MikroTik] > /ip dns set servers=8.8.8.8,1.1.1.1
# Χωρίς output = επιτυχία. Το RouterOS σιωπά σε επιτυχημένες αλλαγές.

[admin@MikroTik] > /ip firewall filter add \
    chain=input \
    protocol=tcp \
    dst-port=22 \
    src-address=192.168.10.0/24 \
    action=accept \
    comment="Allow SSH from MGMT VLAN"
# Το \ στο τέλος κάθε γραμμής συνεχίζει την εντολή στην επόμενη γραμμή.
# Αυτό είναι απλά για αναγνωσιμότητα — μπορείς επίσης να το πληκτρολογήσεις όλο σε μία γραμμή.

# ── PRINT για να επαληθεύσεις τι προστέθηκε ──────────────────────────────
[admin@MikroTik] > /ip firewall filter print
 0  chain=input  action=accept  protocol=tcp  src-address=192.168.10.0/24
    dst-port=22  comment="Allow SSH from MGMT VLAN"
# Κάνε πάντα print μετά την προσθήκη για να επιβεβαιώσεις ότι ο κανόνας φαίνεται σωστός.

# ── SET: επεξεργάσου μία υπάρχουσα καταχώρηση με αριθμό σειράς ──────────
[admin@MikroTik] > /ip firewall filter set 0 comment="SSH from MGMT only — updated"
# "0" = αριθμός σειράς από το output του print. Αλλάζει μόνο το καθορισμένο πεδίο.

# ── SET με χρήση find — πιο ασφαλές από hardcoded αριθμούς σειράς ───────
[admin@MikroTik] > /ip firewall filter set \
    [find comment~"SSH from MGMT"] \
    comment="SSH MGMT — reviewed May 2026"
# Το [find ...] εντοπίζει καταχωρήσεις με τιμή πεδίου αντί για σταθερό αριθμό σειράς.
# Αυτό είναι πιο ασφαλές σε scripts — οι αριθμοί σειράς μετατοπίζονται όταν κανόνες προστίθενται/αφαιρούνται.

# ── DISABLE / ENABLE: εναλλαγή χωρίς διαγραφή ────────────────────────────
[admin@MikroTik] > /ip firewall filter disable 0
# Οι απενεργοποιημένες καταχωρήσεις δείχνουν μια σημαία X στο output του print — υπάρχουν αλλά δεν πυροδοτούνται.

[admin@MikroTik] > /ip firewall filter enable 0

# ── REMOVE: διάγραψε μία καταχώρηση μόνιμα ───────────────────────────────
[admin@MikroTik] > /ip firewall filter remove 0
# Μόνιμο. Χωρίς prompt επιβεβαίωσης. Κάνε πάντα print πρώτα για να επιβεβαιώσεις
# τον σωστό αριθμό σειράς πριν αφαιρέσεις.
⚠ Παγιδα — Οι Αριθμοι Σειρας Μετατοπιζονται Μετα το Remove

Αφού αφαιρέσεις τη σειρά 0, αυτό που ήταν σειρά 1 γίνεται σειρά 0, η σειρά 2 γίνεται σειρά 1, και ούτω καθεξής. Αν αφαιρείς πολλαπλές καταχωρήσεις σε βρόχο, αφαίρεσε από κάτω προς τα πάνω (μεγαλύτερο αριθμό πρώτα), ή χρησιμοποίησε selectors [find ...] αντί για αριθμούς σειράς. Το να αφαιρέσεις τη σειρά 0 δύο φορές στη σειρά διαγράφει δύο διαφορετικές καταχωρήσεις.

Ο Selector find — το Πιο Ισχυρο Εργαλειο σου

Το [find ...] επιστρέφει το εσωτερικό ID καταχωρήσεων που ταιριάζουν σε μια συνθήκη. Χρησιμοποίησέ το με set, remove, enable, και disable αντί για αριθμούς σειράς. Δουλεύει ακόμα κι αν οι σειρές αναδιαταχθούν.

RouterOS — patterns selector [find] 
# Βρες κατά comment (match περιέχει)
[admin@MikroTik] > /ip firewall filter remove [find comment~"temp"]

# Βρες κατά ακριβή τιμή
[admin@MikroTik] > /interface disable [find name="ether3"]

# Βρες απενεργοποιημένες καταχωρήσεις και ενεργοποίησε τις όλες
[admin@MikroTik] > /ip firewall filter enable [find disabled=yes]

# Βρες κατά chain και action μαζί
[admin@MikroTik] > /ip firewall filter print \
    where chain=forward and action=drop
# Το print where χρησιμοποιεί επίσης το ίδιο syntax field=value με το find.

07

Cheatsheet Συντομευσεων Πληκτρολογιου

Αυτές οι συντομεύσεις δουλεύουν σε κάθε session terminal RouterOS. Απομνημόνευσε τις πέντε πρώτες και θα επεξεργάζεσαι δέκα φορές πιο γρήγορα.

ΠληκτροΤι κανει
TabAutocomplete εντολή, παράμετρο, ή τιμή. Πάτα δύο φορές για να δεις όλες τις επιλογές.
?Δείξε διαθέσιμες εντολές ή επιλογές παραμέτρων στην τρέχουσα θέση cursor.
↑ / ↓Κάνε κύκλο μέσα από το ιστορικό εντολών. Επεξεργάσου την ανακτημένη εντολή πριν πατήσεις Enter.
Ctrl+CΑκύρωσε την τρέχουσα εντολή ή διέκοψε μια εντολή που τρέχει (π.χ. ένα μακρύ ping).
Ctrl+XΕπιβεβαίωσε και βγες από safe mode, κρατώντας όλες τις αλλαγές που έγιναν κατά το session.
F1Δείξε πλήρη σελίδα βοήθειας για το τρέχον context ή εντολή.
Home / EndΠήδα στην αρχή ή στο τέλος της τρέχουσας γραμμής input.
Ctrl+AΠήδα στην αρχή της γραμμής (ίδιο με Home — χρήσιμο σε sessions SSH).
Ctrl+EΠήδα στο τέλος της γραμμής (ίδιο με End).
Ctrl+KΔιάγραψε από τον cursor μέχρι το τέλος της γραμμής — χρήσιμο για να ξαναγράψεις το τέλος μιας εντολής.
Ctrl+UΔιάγραψε από τον cursor μέχρι την αρχή της γραμμής.
Ctrl+WΔιάγραψε την προηγούμενη λέξη.
/Επίστρεψε στο root context από οπουδήποτε.
..Ανέβα ένα επίπεδο context.

09

Ενα Πληρες Workflow — Απο την Αρχη μεχρι το Τελος

Βάζοντας τα όλα μαζί: μπες σε safe mode, διάβασε την τρέχουσα κατάσταση, κάνε μια αλλαγή, επαλήθευσέ την, επιβεβαίωσε.

Αυτό το παράδειγμα προσθέτει μια καταχώρηση server DNS και επαληθεύει το αποτέλεσμα. Δείχνει την πλήρη πειθαρχία: safe mode → διάβασμα → γράψιμο → επαλήθευση → επιβεβαίωση.

RouterOS — πληρες workflow με safe mode 
# Βήμα 1: Μπες σε safe mode (αυτόματο rollback αν κάτι πάει στραβά)
[admin@MikroTik] > /system safe-mode
Entering Safe Mode
Press Ctrl+X to exit safe mode
[Safe Mode][admin@MikroTik] >
# Το prompt τώρα δείχνει [Safe Mode] — οι αλλαγές θα κάνουν auto-revert σε 9 λεπτά
# αν δεν επιβεβαιώσεις με Ctrl+X.

# Βήμα 2: Διάβασε την τρέχουσα κατάσταση
[Safe Mode][admin@MikroTik] > /ip dns print
         servers: 8.8.8.8
  dynamic-servers: 203.0.113.1
   use-doh-server:
# Αυτή τη στιγμή μόνο 8.8.8.8 — θέλουμε να προσθέσουμε 1.1.1.1 σαν backup.

# Βήμα 3: Κάνε την αλλαγή
[Safe Mode][admin@MikroTik] > /ip dns set servers=8.8.8.8,1.1.1.1
# Χωρίς output = επιτυχία.

# Βήμα 4: Επαληθευσε
[Safe Mode][admin@MikroTik] > /ip dns print
         servers: 8.8.8.8,1.1.1.1  ← και οι δυο servers τωρα λιστάρονται

# Βήμα 5: Δοκίμασε ότι η αλλαγή δουλεύει
[Safe Mode][admin@MikroTik] > /ping 1.1.1.1 count=2
  0 1.1.1.1  56  55  12ms  echo reply
  1 1.1.1.1  56  55  11ms  echo reply
  sent=2 received=2 packet-loss=0%

# Βήμα 6: Επιβεβαίωσε αλλαγές (βγες από safe mode, κρατώντας τα πάντα)
[Safe Mode][admin@MikroTik] > Ctrl+X
Exiting Safe Mode — changes kept
[admin@MikroTik] >
# Το πρόθεμα Safe Mode έφυγε. Οι αλλαγές είναι μόνιμες.
💡 Ο Χρυσος Κανονας — Προσθεσε Παντα ενα comment=

Κάθε εντολή add θα έπρεπε να περιλαμβάνει μια παράμετρο comment="...". Σε έξι μήνες από τώρα, δεν θα θυμάσαι γιατί υπάρχει ένας κανόνας firewall. Ούτε ο συνάδελφός σου. Ένα comment σαν "Allow CCTV outbound — requested by manager 2026-03" παίρνει 5 δευτερόλεπτα να γραφτεί και εξοικονομεί ώρες debugging. Ο selector [find comment~"..."] γίνεται επίσης πολύ πιο χρήσιμος όταν τα πάντα έχουν ένα ουσιαστικό comment.

Βασικα Συμπερασματα

  1. Το Tab και το ? δεν είναι απάτη — είναι το επαγγελματικό workflow. Κάθε έμπειρος operator χρησιμοποιεί συνεχώς το Tab. Αποτρέπει typos και αναδεικνύει παραμέτρους που δεν ήξερες ότι υπήρχαν. Μην πληκτρολογείς ποτέ μια πλήρη εντολή από μνήμης όταν το Tab μπορεί να το κάνει για σένα.
  2. Κάνε πάντα print πριν αλλάξεις, και ξανά μετά. Διάβασε την τρέχουσα κατάσταση, κάνε μία αλλαγή, επαλήθευσε το output. Αυτή η πειθαρχία πιάνει λάθη πριν προκαλέσουν προβλήματα και επιβεβαιώνει ότι η αλλαγή σου έκανε πραγματικά αυτό που περίμενες.
  3. Χρησιμοποίησε safe mode για κάθε αλλαγή σε έναν live router. Το /system safe-mode δεν κοστίζει τίποτα και σου δίνει ένα rollback 9 λεπτών. Η μία φορά που το παραλείπεις και σπας πρόσβαση SSH σε έναν απομακρυσμένο router ξενοδοχείου είναι η φορά που θα ευχηθείς να μην το είχες κάνει.
  4. Χρησιμοποίησε [find comment~"..."] αντί για αριθμούς σειράς σε scripts και συχνές λειτουργίες. Οι αριθμοί σειράς μετατοπίζονται. Τα comments όχι. Οποιοδήποτε script ή διαδικασία που αναφέρεται σε κανόνες κατά θέση θα σπάσει τελικά — τα comments είναι σταθεροί αναγνωριστές.
  5. Το CLI δεν είναι διαφορετικό εργαλείο από το Winbox — είναι το ίδιο εργαλείο. Κάθε κλικ στο Winbox είναι μια εντολή CLI. Μόλις δεις την αντιστοιχία, το CLI γίνεται πιο φυσικό από το Winbox για τις περισσότερες εργασίες: είναι πιο γρήγορο, copy-pasteable, scriptable, και προσβάσιμο μέσω SSH από οπουδήποτε.
  6. Η σιωπή σημαίνει επιτυχία. Το RouterOS δεν τυπώνει μήνυμα επιβεβαίωσης όταν μια εντολή πετυχαίνει. Τυπώνει output μόνο όταν υπάρχει κάτι να δείξει, ή ένα μήνυμα error όταν κάτι αποτυγχάνει. Αν πληκτρολογήσεις μια εντολή και τίποτα δεν εμφανίζεται — δούλεψε. Επαλήθευσε με print.
  7. Πρόσθεσε πάντα ένα comment σε κάθε καταχώρηση που δημιουργείς. Σε έξι μήνες από τώρα, τα comments είναι η διαφορά ανάμεσα στο να καταλαβαίνεις αμέσως το config σου και στο να περνάς μια ώρα κάνοντας reverse-engineer.

Χρειαζεσαι configuration on-site και σωστα καταγεγραμμενο;

Παρέχω managed network services και configuration on-site για ιδιοκτησίες φιλοξενίας, και καταγράφω τα πάντα καθώς προχωράω — όχι για να παραμένω απαραίτητος, αλλά ώστε η δική σου ομάδα να μπορεί πραγματικά να το συντηρήσει αφού φύγω.
